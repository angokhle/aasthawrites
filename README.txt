AASTHA — COPYWRITING THAT TELLS A BIGGER STORY
Responsive website prototype based on the screenshot selected in the conversation.

HOW TO VIEW
1. Extract this folder.
2. Open index.html in Chrome, Safari, Edge or Firefox.
3. The HTML, CSS, JavaScript and images work locally without an internet connection.

WHAT IS INCLUDED
- index.html : full homepage, filtered portfolio, project detail dialogs, writing, about
- contact.html : intentional contact-page placeholder (to be designed later)
- assets/styles.css : responsive website styling
- assets/app.js : filtering, mobile navigation, project dialogs
- assets/work-data.js : 26 curated work samples from Aastha's portfolio
- assets/*.webp : decorative images based on the selected visual mockup and real project images extracted from the user's portfolio
- Aastha portfolio.pdf : original 30-page portfolio, linked from every project dialog

FUNCTIONALITY
- Filter work by Reel scripts / Billboards / Social / Long-form / Spec work / Poetry
- Show More loads six additional portfolio cards per click
- Open each card to see the brief, excerpts and source PDF page
- Published reel and article links (where present in original PDF) open externally
- Responsive mobile hamburger navigation
- On-page navigation for Work, Writing and About
- Contact is provisioned but does not have a submission form yet

DESIGN NOTES
- Decorative homepage photography comes from the reference visual provided.
- Portfolio case art comes from the supplied PDF (where images exist).
- The homepage is a prototype; publication-quality photos may be licensed or replaced prior to launch.
- No fabricated campaign performance statistics have been added.
- External published links require internet and may be subject to permissions.
